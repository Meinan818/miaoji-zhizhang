# 设计规范

喵叽智账的视觉方向是「猫猫手账」：奶油纸色打底，柔粉与浅绿做状态色，圆润边角、轻微颗粒和贴纸感，不用立体 emoji 和重阴影。整套语言在首页、聊天、明细、统计、个人页保持一致。

## 颜色

色彩集中在 `frontend/src/styles/home-visual-tokens.css` 与 Tailwind 配置里，页面不直接写死色值。

| 用途 | 变量 | 色值 |
|---|---|---|
| 页面底色 | `--zz-home-bg` | `#fdfaf3` |
| 次级底色 | `--zz-home-bg-alt` | `#f7f0e7` |
| 纸面 | `--zz-home-paper` / `.paper-surface` | `#fffdf8` |
| 主文字 | `--zz-home-ink` | `#3c261a` |
| 次级文字 | `--zz-home-ink-soft` | `#79634f` |
| 分割线 | `--zz-home-line` | `#d9cbb6` |
| 主强调（金额便签、按钮） | `--zz-home-yellow` | `#fed76e` |
| 支出 / 柔粉 | `--zz-home-pink` / `--zz-home-pink-soft` | `#9d6865` / `#f8dfda` |
| 收入 / 浅绿 | `--zz-home-green` / `--zz-home-green-soft` | `#58705a` / `#eff3dd` |

约定：收入用绿系、支出用粉系，同一含义在各页面用同一组颜色；强调色只用于金额、主按钮和当前项，不做大面积铺色。

## 字体

- 字体栈 `--zz-home-font`：`"Noto Sans SC", "Microsoft YaHei UI", "微软雅黑", sans-serif`。
- 标题与正文统一轻字重，避免黑体/楷体混搭；金额数字加大字重保证可读性。
- 正文最小 14px，辅助信息 12–13px；不使用全大写英文标签。

## 材质

- 纸面：`.paper-surface` 用底色 + 四层 radial-gradient 叠加（暖黄、柔粉、薄荷的柔光斑 + 20px 点阵），模拟手账纸的颗粒感。
- 卡片：圆角 16–24px，1px 浅色描边，阴影不超过 `0 8px 24px rgba(60,38,26,.08)`。
- 贴纸与胶带：用于状态标签、金额便签、确认流程与书签式入口，避免整块纯色矩形。
- 动效：只做 120–200ms 的位移/透明度过渡，不做循环动画。

## 组件风格

| 组件 | 约定 |
|---|---|
| 导航 | 底部轻导航，当前项用柔粉底 + 图标着色；中央是进聊天的加号 |
| 账单卡片 | 纸片式，左侧分类图标，右侧金额靠右对齐；整行可点进入编辑 |
| 聊天消息 | 用户气泡在右、助手在左，草稿与确认卡片有独立底影，不打断对话 |
| 表单 | 复用同一套输入与校验，错误提示贴在字段下方，按钮固定区分保存/取消 |
| 图表 | ECharts，配色取自上面 5 个语义色，不使用默认主题色 |
| 头像 | 预置 SVG 头像或用户上传照片裁成 256px，圆形，1px 描边 |

## 图标与吉祥物

- 界面图标用 `lucide-vue-next` 线性图标，尺寸 16/20/24。
- 吉祥物是二维手绘猫，无正式名字、自称「本喵」；首页用 `miao-avatar.png`，聊天用 `miao-avatar-fluffy-v1.png`。
- 姿态图在 `frontend/src/assets/design/mascot/poses/`，`manifest.json` 记录 active/reserved 状态与文件哈希；不使用未审核素材。

## 页面骨架

| 页面 | 结构 |
|---|---|
| 首页 | 纸片日历（可切月、选日、看当天小计）→ 当天账单小票 → 轻导航 |
| 聊天 | 顶部头像与引导 → 消息流（草稿/确认卡片）→ 输入区（含手动记账入口） |
| 明细 | 月份与筛选条 → 分组账单列表 → 结果小计与导出 → 整行编辑面板 |
| 统计 | 月份切换 → 收支结余与笔数 → 分类占比图 → 查看明细入口 |
| 个人页 | 资料卡（昵称/签名/头像）→ 账本概览与近七天足迹 → 备份与退出 |

## 无障碍与适配

- 所有可点区域提供键盘可达的焦点态；焦点环在浅底上保持 3:1 以上对比。
- 交互元素用原生 `button`/`input`/`dialog`，对话框有 `role="dialog"` 与焦点回收。
- 320px 起布局可用，固定底栏留出滚动余量，长文本换行而不是截断。
- 语义色不单独承载信息，收入/支出同时有文字或图标标注。
